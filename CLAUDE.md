# Pocket-Onyx — fork do Márcio

Este é um fork de [28spawn/Pocket-Onyx](https://github.com/28spawn/Pocket-Onyx), o firmware aberto
Onyx para a M-VAVE Pocket Amp. A documentação e o código são os do projeto original; comece pelo
`README.md`, pelo `ARCHITECTURE.md` e pelo `RECOVERY.md`.

## Projeto relacionado (em desenvolvimento)

O fork serve ao projeto **Pocket Tone**, cujo plano, decisões e pesquisa ficam em
https://github.com/marciomerconi/pocket-tone. Antes de qualquer mudança aqui, leia o `ESTADO.md` e
o `docs/diretrizes/seguranca.md` de lá.

O ramo `main` acompanha o projeto original. Mudanças próprias entram em ramos separados.
